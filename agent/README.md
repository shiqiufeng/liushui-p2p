# liushui-agent · 被控端本地代理

网页受浏览器沙箱限制，**无法**直接向操作系统注入鼠标键盘事件。要让别人远程控制这台电脑，
被控端必须运行本程序：网页负责 WebRTC 传输与屏幕采集，本程序只负责把收到的指令转成本机输入。

## 编译

```bash
cd agent
go build -trimpath -ldflags "-s -w" -o liushui-agent.exe .
```

零第三方依赖，只需要 Go 1.21+。产物约 7 MB，单文件，无需安装运行时。

## 运行

```bash
./liushui-agent.exe                     # 自动打开浏览器并进入站点
./liushui-agent.exe -room 1234          # 直接进入指定房间
./liushui-agent.exe -no-browser         # 只启动本地服务
./liushui-agent.exe -port 17877         # 自定义端口
```

启动后：

1. 自动打开 `https://p2p.liushuile.dpdns.org/zh?agentPort=...&agentToken=...`
2. 网页通过 `ws://127.0.0.1:<port>/control?token=<一次性令牌>` 连上本程序
3. 令牌每次运行随机生成，程序退出即失效，防止其他网页劫持控制通道

## 使用流程

| 角色 | 操作 |
| --- | --- |
| 被控端 | 运行 `liushui-agent.exe` → 进入房间 → 对方请求时点「允许并共享屏幕」 |
| 控制端 | 进入同一房间 → 点底部「远程控制」→ 对方同意后进入全屏控制画面 |

- 控制端按 `Esc` 退出控制；被控端按 `Esc` 立即断开
- 所有控制指令走 data channel，受应用层 E2EE 保护（见 `src/client/lib/e2ee.ts`）
- 屏幕画面走标准 WebRTC 屏幕共享，中继/直连自动选择

## 权限说明

- 普通权限即可控制普通程序窗口
- 若要操作以管理员身份运行的窗口（任务管理器、UAC 提权后的程序），本程序也需要以管理员身份启动
- 若 Windows 启用了「UIPI」限制，跨完整性级别的输入会被系统丢弃，这属于系统行为

## 安全边界

- 令牌校验失败直接返回 403，不建立控制通道
- 同一时刻只允许一个控制连接，后到的连接会被拒绝
- 端口只监听 `127.0.0.1`，局域网内其他机器无法直连本代理
- 被控端每次授权都需要用户手动点击，不存在静默接管
